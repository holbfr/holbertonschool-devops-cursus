# TASK 0 Commands 

#### Build the image:
```
docker build -t flask-health-app .
```

#### Run the container:
```
docker run --rm -p 5000:5000 flask-health-app
```

#### Then access:
```
http://127.0.0.1:5000/
http://127.0.0.1:5000/health
http://127.0.0.1:5000/kill
```
